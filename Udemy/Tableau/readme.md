# 🌍 Demographic Evolution - World Demographic Analysis

![Tableau](https://img.shields.io/badge/Tableau-Public-FF6E1E?logo=tableau)

## Descripción

Dashboard interactivo en Tableau Public que analiza la evolución demográfica mundial, permitiendo explorar tendencias poblacionales, cambios demográficos y proyecciones globales a lo largo del tiempo.

**🔗 [Ver Dashboard en Vivo](https://public.tableau.com/views/DemographicEvolution_17676502860510/WorldDemographic)**

---

## Objetivos del Proyecto

- Visualizar la evolución histórica de la población mundial
- Analizar tendencias demográficas a lo largo del tiempo
- Identificar patrones de crecimiento poblacional por región/país
- Explorar proyecciones futuras de población
- Facilitar la exploración interactiva de datos demográficos

## Características del Dashboard

### Visualizaciones Incluidas:

- Mapas geográficos con distribución poblacional mundial
- Gráficos temporales de evolución poblacional (1960-2013)
- Filtros interactivos por país/región
- KPIs de población total, crecimiento y densidad
- Tendencias de crecimiento con proyecciones

### Métricas Clave:

- Población total mundial
- Tasa de crecimiento anual
- Densidad poblacional
- Fertilidad por región
- Esperanza de vida
- Migración neta

## Contexto Global

Pero datos relevantes incluidos en el análisis:

- Población mundial 2025: ~8.2 billones
- Población mundial 2026: ~8.3 billones
- Población mundial 1960: ~3 billones
- Crecimiento en 65 años: +5.2 billones

Datos de: [UN World Population Prospects](https://population.un.org/wpp/) y [World Bank](https://data.worldbank.org/)

## Cómo Explorar el Dashboard

### Opción 1: Tableau Public (Recomendado)

1. Visita el dashboard en vivo: [Demographic Evolution](https://public.tableau.com/views/DemographicEvolution_17676502860510/WorldDemographic)
2. Usa los filtros para seleccionar país/región
3. Desliza el slider de tiempo para ver evolución
4. Interactúa con los gráficos para drill-down

### Opción 2: Descargar Workbook

1. En Tableau Public, haz clic en File > Download Workbook
2. Abre con Tableau Desktop o Tableau Public (gratuito)
3. Explora los datos localmente

## Notas Importantes

- Los datos de proyecciones son estimaciones basadas en tendencias históricas
- Las proyecciones pueden variar según supuestos de fertilidad, mortalidad y migración
- El dashboard está optimizado para Tableau Public (gratuito)
- Los datos se actualizan periódicamente según nuevas estimaciones de la ONU
